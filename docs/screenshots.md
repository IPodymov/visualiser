Основные файлы пересняты 24 августа 2026 года (`v=20260824-2`), раздел сравнения с прошлым годом — 26 октября 2026 года (`v=20261026-1`). Query-версия нужна для сброса кеша GitHub после замены PNG.

Раздел сравнения снят headless Chrome на всю высоту страницы и обрезан до секции (`sips -c <высота> 1440 --cropOffset <y> 0`). Перед следующей съёмкой примените миграции и ожидаемый импорт (текущий год и архив), проверьте число программ, очистите browser state и измените query-версию во всех Markdown-ссылках.
