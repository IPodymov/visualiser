# Документация EduPlan Compare

Документация описывает текущее состояние кода и пользовательского интерфейса. При изменении контракта, сценария или инфраструктуры обновляйте соответствующий документ в том же pull request.

## Поддержка актуальности

Документация считается частью продукта. Перед merge проверьте относительные ссылки, примеры команд, названия env-переменных и соответствие скриншотов текущим данным. Скриншоты README должны получать новую версию query-параметра после каждого обновления, чтобы GitHub не показывал кешированный файл.
